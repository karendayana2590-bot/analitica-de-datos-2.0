Colab paso a paso

  1. Pulsa Abrir el cuaderno de esta clase en Colab. El archivo se llama Clase_1_pandas_desde_cero.ipynb.
  2. Guarda una copia en Drive desde el menú Archivo. Así conservarás tu trabajo en tu propia copia.
  3. Conecta el entorno de ejecución. Lee la primera explicación y ejecuta la primera celda con Mayús + Intro.
  4. La primera celda prepara produccion.csv si falta. Los datos están incluidos: puedes comenzar sin subir archivos.
  5. Ejecuta las celdas de arriba abajo. Después de reiniciar el entorno, vuelve a ejecutar la preparación.
  6. Antes de entregar, guarda el cuaderno, reinicia el entorno y ejecuta todas las celdas. Descarga también los CSV que generes.
Si prefieres Jupyter en tu equipo

Descarga el cuaderno y los datos desde Materiales. Guárdalos en una misma carpeta. Abre el cuaderno en Jupyter con pandas instalado y ejecuta desde la primera celda. Si aparece ModuleNotFoundError, instala pandas en el mismo entorno que utiliza el cuaderno.

python -m pip install jupyterlab pandas
python -m jupyterlab
